# Introduction to ReactJS Project

A beginner React project with a simple counter component. The app was created with Create React App and uses component files plus CSS styling to practice the basics of rendering and updating UI in React.

## Features

- React app shell
- Counter component
- Component-specific CSS
- Create React App structure

## Tech Stack

- React
- Create React App
- JavaScript
- CSS

## Project Structure

```text
src/
  App.js
  App.css
  componets/
    Counter.js
    counter.css
```

Note: the folder is named `componets` in the current project source.

## How To Run

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open:

```text
http://localhost:3000
```

## Available Scripts

```bash
npm start      # Run the app locally
npm test       # Run the CRA test runner
npm run build  # Build for production
```
